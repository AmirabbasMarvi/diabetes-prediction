# Diabetes Prediction using KNN

A simple machine learning project to predict diabetes based on medical features using K-Nearest Neighbors (KNN) algorithm and data normalization with StandardScaler.

## Preprocessing
- Features normalized using `StandardScaler` from `sklearn.preprocessing`

## Model
- **Algorithm:** K-Nearest Neighbors (KNN)
- **Library:** scikit-learn

##  Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Jupyter Notebook
